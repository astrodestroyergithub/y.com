# Y.com — The Unbiased Global Town Square (Netlify Production Bundle)

Welcome to **Y.com**, the open, non-biased global social platform designed as the citizen-first competitor to X.com, powered by **Nimbak AI 3.5** and **Nimbak Imagine Studio**.

## 🚀 Instant Netlify Deployment (3 Options)

### Option 1: Netlify Drag-and-Drop (Fastest — 10 Seconds)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this entire unzipped folder (or `Y-com-netlify-ready.zip` directly) into the browser window.
3. Your site will deploy immediately with HTTPS, global CDN caching, and SPA routing pre-configured via `netlify.toml` and `_redirects`.

### Option 2: Netlify CLI
```bash
npx netlify-cli deploy --prod --dir=.
```

### Option 3: Git Continuous Deployment (GitHub / GitLab / Bitbucket)
1. Push these files to a repository.
2. Connect the repository in Netlify.
3. Keep `Publish directory` set to `.` (automatically read from `netlify.toml`).
